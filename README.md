# Python Practice – Basic Programming Exercises

This repository contains a collection of **Python programming practice exercises** designed to build and strengthen fundamental Python programming skills.

The notebook covers basic concepts such as:

* Taking user input and displaying output
* Arithmetic operations
* Conditional statements (`if`, `elif`, `else`)
* Comparison and logical operators
* `for` and `while` loops
* Functions
* Number-based problems
* Checking positive, negative, and zero values
* Finding the greatest among numbers
* Checking leap years
* Vowel and consonant identification
* Range checking
* Student grade calculation
* Electricity bill calculation
* Generating even and odd numbers
* Printing numbers within a given range
* Basic mathematical calculations

### Purpose

The purpose of this notebook is to gain **hands-on practice with Python fundamentals** and develop problem-solving skills through simple programming exercises.
